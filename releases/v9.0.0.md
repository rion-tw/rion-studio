### BREAKING CHANGES

* Rion Studio now runs only on the Electron-bundled Chromium desktop runtime; the Tauri/System WebView shell is retired.
* The typed Rion bridge now requires Extensions command, store
and event methods, and the Core command/event unions include Extensions
variants. Bridge implementations and exhaustive consumers must adopt the
updated contracts together. Extensions execution requires the Chromium v23
runtime; the stable Tauri adapter reports the capability as unsupported.
