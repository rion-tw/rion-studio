# Distribution Notice

The [public distribution repository](https://github.com/rion-tw/rion-studio) is
the product-support and download home for Rion Studio. It contains product
documentation, legal notices, issue tracking, and compiled release assets. The
complete application source code and build system are not published there.

Release installers are provided under the terms listed in
[`docs/legal`](docs/legal/README.md). Third-party notices are available in
[`docs/legal/THIRD_PARTY_NOTICES.md`](docs/legal/THIRD_PARTY_NOTICES.md).
